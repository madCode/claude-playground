# Sample blog

A small Jekyll blog for trying Jekyll Poster against, and the fixture its tests read. Sample
content only. Its posts cover the front matter shapes real blogs use: a YAML list of categories,
a space-separated string, a single `category:`, categories from a folder (`travel/_posts`), posts
in a dated subfolder, a draft, and a post with `published: false`.

To try the app on it, copy this folder into a new public repository, turn on GitHub Pages
(Settings › Pages › Deploy from a branch, `main`, `/`), and point the app at that repository.
