# Spotter

Which dumbbell to grab for each exercise in today's Orange Theory class, from one glance before
you walk in, and a one-minute log in the car afterwards.

- It reads the day's workout from the boards members post on r/orangetheory, and which class
  you're taking from your calendar.
- Every number says why, one tap away, and warnings (a miss, a twinge) come first.
- Your history stays on your phone, in Android backup and in exports to a folder you pick.

Install it on an Android phone from
[the debug build](https://github.com/madCode/claude-playground/releases/download/spotter-debug/spotter-debug.apk);
after that it updates itself ([how to check](docs/DEVICE.md)).
